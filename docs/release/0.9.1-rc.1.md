# VaporLensDB 0.9.1 RC 1

This is a **pre-release build for public RC testing**. It is not a stable or
production-ready release.

## Highlights

- Tier-A native PostgreSQL, MySQL, and SQLite CSV imports now use database
  parameter binding in batch and fallback paths.
- PostgreSQL CSV fallback recovers through savepoints after constraint failures,
  and wide-table imports respect parameter budgets.
- CSV Preview can be cancelled through the existing task lifecycle.
- MySQL statement splitting handles backslash-escaped strings under the supported
  default SQL mode.
- macOS packaging now keeps the staged QA App as the sole long-lived release-like
  application identity, avoiding duplicate LaunchServices search results.

## Validation

- The deterministic repository gate, frontend tests, workflow smoke suite,
  Rust tests, lint, formatting, clippy, packaging tests, and bundle budgets pass.
- Native PostgreSQL and MySQL parameterized CSV imports passed production-path
  tests against disposable QA databases, including multi-batch, transaction,
  constraint-fallback, NULL, Unicode, special-character, SQL-looking-value, and
  cleanup cases.
- SQLite parameterized CSV behavior is covered by deterministic tests.
- Two consecutive macOS packaging builds completed with the expected staged App,
  DMG, and checksum while retaining only one ordinary LaunchServices identity.

## Supported platform

- **macOS arm64 only** for this RC artifact.
- macOS Tier-A runtime evidence covers native PostgreSQL, MySQL, and SQLite.
- Windows and Linux desktop runtime remain **NOT EXECUTED** and have no assets in
  this RC.

## Known limitations

- SQL Server parameterized CSV import is unsupported.
- JDBC parameterized CSV import is unsupported, including Oracle and custom JDBC
  paths.
- MySQL CLI `DELIMITER` directives are unsupported.
- PostgreSQL exotic and multidimensional types are outside the supported scope.
- Full re-query export accepts one SQL statement; multi-statement and multi-result
  full re-query export are unsupported.
- Oracle JDBC and custom JDBC remain experimental / best-effort and require
  user-provided driver JARs.
- The result grid is read-only.

## Signing and notarization

The macOS App is **ad hoc signed** and **not Apple notarized**. Gatekeeper may
warn about or block the DMG/App after download from the internet. This is a known
limitation of this RC test distribution; it is not a Developer ID signed or
Apple-notarized stable release. Do not disable Gatekeeper or use an automated
security-bypass script.

## Checksum verification

Download both release assets from this GitHub Pre-release:

- `VaporLensDB.dmg`
- `SHA256SUMS.txt`

From the directory containing both files, run:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

The expected result is:

```text
VaporLensDB.dmg: OK
```
