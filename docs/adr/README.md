# Architecture Decision Records

This directory is reserved for Architecture Decision Records.

Current repository documentation captures the active decisions in:

- `CONTEXT.md`
- `docs/VaporLensDB-Design.md`

Add a separate ADR here when a future decision changes architecture, persistence
format, IPC contracts, driver strategy, release process, or security posture in
a way that should be reviewed independently.
